❓ COMMON QUESTIONS:

Q: Why OAuth2 instead of username/password?
A: More secure, designed for server automation, no password in code

Q: Does the token expire?
A: Yes (1 hour), but notebooks auto-refresh - you don't need to do anything

Q: What if I hit rate limits?
A: Tokens are cached, so just use normally. Rate limits only if requesting
   new tokens >5 times per minute

Q: How do I use this in a Slurm job?
A: Add the export commands to your job script (same as local)

Q: How do I change credentials?
A: Delete old OAuth client in Copernicus Dashboard, create new one,
   update .bashrc
